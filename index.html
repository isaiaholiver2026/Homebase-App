    Stocks

    Watchlist sheet Your tickers and prices come from the Google Sheet "Home Base – Watchlist (standalone)". To add a ticker, type it into column A of any empty row. The sheet needs Share → General access set to "Anyone with the link" (Viewer). Open the sheet
    How to get this link (one time)
    1. Open the sheet and choose File → Share → Publish to web.
    2. Pick the sheet tab, then change "Web page" to Comma-separated values (.csv).
    3. Click Publish, confirm, and copy the link it shows.
    4. Paste it in the box above.
    Google updates published sheets about every 5 minutes. Anyone with that link can see your ticker list.

    Canvas

    Where to find this link
    1. In Canvas, open Calendar from the left sidebar.
    2. At the bottom right, click Calendar Feed.
    3. Copy the link it shows and paste it above.
    Anyone with this link can see your Canvas calendar, so keep it private. Home Base only keeps it in this browser (and in backups you download).
